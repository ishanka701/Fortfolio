A personal portfolio website showcasing my skills, experience, and projects as a Data Analyst, ML Engineer, and Graphic Designer.

## Overview

This is a single-page, responsive portfolio site built with vanilla HTML, CSS, and JavaScript. It includes a profile/hero section, an about section, an experience/skills breakdown, a projects showcase, and a contact section — with a mobile-friendly hamburger navigation menu.

## Sections

- **Profile** - Intro, title, CV download button, and social links (LinkedIn, GitHub)
- **About** - Short bio, years of experience, and education background
- **Experience** - Programming languages and graphic design skills with proficiency levels
- **Projects** - Showcase of recent projects with links to GitHub repos and live demos
- **Contact** - Email and LinkedIn contact links
- **Footer** - Quick navigation links and copyright

## Tech Stack

- **HTML5** - Page structure
- **CSS3** - Styling (`style.css`)
- **JavaScript** - Hamburger menu toggle for mobile navigation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ishanka701/portfolio.git
   cd portfolio
   ```

2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   # Using Python
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser.

## Customization

- Update personal details, bio, and skills in `index.html`
- Replace images/icons in the `Asset/` folder with your own
- Update project links (`Github` / `Live Demo` buttons) with real repository and deployment URLs
- Swap `resume-example.pdf` with your actual CV
- Update the email and LinkedIn links in the **Contact** section

## Deployment

This site can be deployed for free using:
- **GitHub Pages** — Push to a repo and enable Pages in repository settings
- **Netlify** / **Vercel** — Drag-and-drop deploy or connect the GitHub repo
